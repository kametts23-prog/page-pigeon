# Page Pigeon 🐦📚

**Send a story. Get a story.**

Page Pigeon is a community-powered physical book lending app. Members list books they own, borrow books from other readers, ship or exchange them locally, join book clubs, and build trust through successful returns.

## MVP goal

Prove one complete transaction:

1. Create an account
2. Add at least 3 books
3. Discover an available copy
4. Request to borrow it
5. Lender accepts
6. Book ships or is exchanged locally
7. Borrower reads it
8. Book is returned
9. Transaction closes and reputation updates

## Stack

- Next.js + TypeScript
- Supabase / PostgreSQL
- Payment provider integration for verified payment methods
- Shipping provider integration for labels and tracking
- ISBN metadata provider

## Brand

Warm, whimsical, modern, and trustworthy. Page Pigeon combines a storybook bookstore with vintage postal details while keeping the product interface clean and accessible.

Working tagline: **Send a story. Get a story.**
